# Estrutura Analítica do Projeto (EAP)
## Sistema de Gerenciamento de Posto de Lavagem

1. Sistema de Gerenciamento de Posto de Lavagem
   1.1. Iniciação e Engenharia de Requisitos
        1.1.1. Levantamento de Requisitos e Entrevistas
        1.1.2. Especificação de Casos de Uso (UC05 e outros)
        1.1.3. Matriz de Requisitos (RFs e RNFs)
   1.2. Modelagem e Arquitetura de Software
        1.2.1. Diagrama de Casos de Uso (UML)
        1.2.2. Diagrama de Classes (UML)
        1.2.3. Diagrama de Estados da O.S. (UML)
        1.2.4. Estrutura Analítica do Projeto (EAP)
   1.3. Prototipação e UI/UX
        1.3.1. Protótipos de Tela (Mobile/Desktop)
        1.3.2. Validação dos Protótipos com Stakeholders
   1.4. Banco de Dados
        1.4.1. Modelo Relacional / DER
        1.4.2. Script DDL de Criação das Tabelas
   1.5. Desenvolvimento da Aplicação
        1.5.1. Backend (API / Autenticação / Regras de Negócio)
        1.5.2. Frontend (Telas de O.S., Clientes, Veículos e Caixa)
        1.5.3. Integração Frontend + Backend
   1.6. Testes e Garantia de Qualidade (QA)
        1.6.1. Testes Unitários e de Integração
        1.6.2. Testes de Aceitação do Usuário (UAT)
   1.7. Implantação e Encerramento
        1.7.1. Configuração do Ambiente de Produção
        1.7.2. Treinamento de Administradores e Recepcionistas
        1.7.3. Documentação Final e Entrega
