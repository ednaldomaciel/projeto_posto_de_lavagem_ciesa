# 🎨 Protótipos de Interface (UI/UX) - Lava Jato do Valmir

Este diretório armazena os artefatos visuais e protótipos estáticos concebidos durante a fase de elicitação e design de interface (UI/UX) do projeto acadêmico (CIESA).

---

## 📁 Estrutura da Pasta

* `frontend/prototipos/prototipacao_tela_recp.html` — Mockup inicial do Painel de Atendimento e Recepção.
* `frontend/prototipos/prototip_tela_status_lavadores.html` — Mockup inicial do Painel do Pátio (Mobile-First para lavadores).
* `frontend/prototipos/prototipo_tela_gerenciamento.html` — Mockup inicial do Painel Administrativo e Caixa.

---

> ℹ️ **Nota de Arquitetura:**
> Estes arquivos são protótipos estáticos de estudo e validação com o cliente (Seu Valmir). Os **templates de produção executáveis** integrados com a lógica de negócio do Django encontram-se na pasta `backend/templates/`.
